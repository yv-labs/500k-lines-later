# Code of Conduct

This project follows the [Contributor Covenant, v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be direct about code, kind to people. Findings describe what broke, not who broke it —
that applies to incidents you report here as much as to the ones in the rules.

Report unacceptable behaviour to the maintainer (YV Labs — Vidh Yasa) via a private GitHub
security advisory or the contact on the GitHub profile. Reports are handled confidentially.
